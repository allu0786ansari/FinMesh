# Evaluation reports

Generated by the CLI; every page names the stamped artifact (under `data/artifacts/`) it was rendered from. Fixture reports are never written here.

| Page | Command | Week |
| --- | --- | --- |
| `harness_check_<ds>.md`: reference scorers through the harness | `finmesh harness-check` | 3 |
| `features_<ds>.md`: feature build rows, time and memory per stage and member, exchange rates | `finmesh features` | 4 |
| `feature_signal_<ds>.md`: each feature alone on validation; leakage smoke test | `finmesh feature-report` | 4 |

From week 5 the experiment runners add their own pages.
