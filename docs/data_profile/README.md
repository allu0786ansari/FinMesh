# Data profiles

Generated by `uv run finmesh week1 --dataset <name>` (or `finmesh profile`). One markdown file per real dataset: `HI-Small.md`, `LI-Small.md`. Do not edit them by hand; regenerate instead. Each file starts with the manifest hash of the data it describes.

Profiles of the synthetic fixture are never written here; they go to `data/artifacts/week01/`.
