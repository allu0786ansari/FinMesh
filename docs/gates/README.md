# Gate notes

One page per gate: `G0.md` (week 2), `G1.md` (week 5), `G2.md` (week 9), `G3.md` (week 12), `G4.md` (week 18). A gate is never skipped. Each note uses this template, and every number cites the stamped artifact it came from. Fixture-based artifacts are refused by `finmesh.eval.provenance.assert_gate_eligible`.

```markdown
# Gate GN · <date>

## Question this gate answers
<one sentence from the proposal>

## Evidence
| Measure | Value | Interval | Artifact (path + manifest hash) |
| --- | --- | --- | --- |

## Decision
<proceed / adjust / fallback>, and the rule from the proposal that decided it.

## Consequences for the plan
<what changes in the next phase, if anything>
```
