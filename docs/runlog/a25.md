### 3. Protected-flag frontier on Medium validation (about 1.5–3 h each)

```bash
uv run finmesh flag-frontier --dataset HI-Medium 2>&1 | tee a25_flag_HI.log
uv run finmesh flag-frontier --dataset LI-Medium 2>&1 | tee a25_flag_LI.log
uv run finmesh flag-select
```

`flag-select` applies the frozen rule:

1. Among candidates within the H1c margin on every assessable target of both datasets, it picks the largest share of plain S1's gain.
2. Ties go to the smaller ε, then to the ungated version.
3. If no candidate qualifies, it picks **none**.

It writes `docs/eval/a25/flag_selection.md`.
